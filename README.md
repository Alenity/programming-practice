 Project 1 - Guessing Game
   - The first project I wrote in Rust when first learning the language.
   - It is a simple guessing game, that works by generating a random number between 1 and 100.
   - The user then guesses via the terminal and the program will guide them to the correct answer with "too low" or "too high" messages.
   - The game ends when the user guess the correct number and the program will display a congratulatory message.
